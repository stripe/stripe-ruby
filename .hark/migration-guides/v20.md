## Rename `Stripe::Reversal` to `Stripe::TransferReversal`

The class representing a transfer reversal has been renamed from `Stripe::Reversal` to `Stripe::TransferReversal`

This change affects integrations that reference `Stripe::Reversal` directly, including class comparisons, `is_a?` checks, and Sorbet type annotations. Replace those references with `Stripe::TransferReversal`:

```ruby
# Before
reversal = Stripe::Transfer.retrieve_reversal("tr_123", "trr_123")
reversal.is_a?(Stripe::Reversal)

# After
reversal = Stripe::Transfer.retrieve_reversal("tr_123", "trr_123")
reversal.is_a?(Stripe::TransferReversal)
```

The methods for creating, retrieving, updating, and listing transfer reversals have not changed. Code that only calls those methods and reads attributes from the returned object does not require an update.
